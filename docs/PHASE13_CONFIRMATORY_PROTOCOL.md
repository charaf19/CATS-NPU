# Frozen Phase 13 confirmatory protocol

**Prospective version 1, 2026-11-03.** This document, `results/phase13/protocol.json`, query selection and experimental/analysis source are committed before generating fresh scores or collecting confirmation outcomes. `results/phase13/freeze.json` records that immutable commit and protocol digest. Execution asserts the frozen source hashes. Historical Phase 7/8 protocols are unaffected. No algorithm is changed in this study.

**Questions.** C1: characterize membership/value/order/tie fidelity on a specified numerical panel. C2: test whether preserving only TopK or only Reshape is insufficient in the actual hierarchy and whether their combination passes. C3: measure the host-to-host cost of checked FP32 versus checked INT32 and practical controls. C1/C2 are fixed-panel experimental observations, not claims of algorithmic novelty or independent defect counts.

**Data selection.** The exact 24 fresh query IDs (eight per dataset) and all excluded historical IDs are frozen in the JSON. Use SHA256-rank selection among unused source query IDs, fixed without inspecting scores. SIFT uses negative squared L2 divided by `128*255^2`, then FP16. BEIR uses the original corpus order/text construction, normalized FP32 embeddings from `sentence-transformers/all-MiniLM-L6-v2` at revision `1110a243fdf4706b3f48f1d95db1a4f5529b4d41`, CUDA batch 256, then cosine scores cast to FP16. No encoder/metric substitution or query exclusion based on scores, ties or latency is allowed. Record source/archive/model/input hashes and generation environment. Score generation is outside TopK timing.

**Performance matrix.** Base panel: full corpus, K=10,W=256 for all eight queries of all three datasets (24 cases). Sensitivity uses only the first two selected queries per dataset: K=1,W=128 and K=100,W=512 on full corpora (12 additional cases). On SIFT's first two queries also use N=16,384 and 131,072 at K=10,W=256, W=128 and 512 at N=1M,K=10, and K=1 and 100 at N=1M,W=256 (12 additional cases). Total **48**, not a Cartesian product. SIFT includes isolated N/K/W changes; BEIR joint K/W settings do not isolate their individual causal effects.

**Methods and I/O.** Existing native OpenVINO NPU direct control (its documented K+1 boundary/tie handling), checked FP16 static hierarchy, stable INT32 hierarchy, checked promoted FP32 hierarchy with `TopK,Reshape` preservation, optimized C++ CPU, and stable CUDA with corrected host tie handling. All consume the same immutable host FP16 scores and return host stable IDs or explicit rejection. Raw numerical operator testing is separate from the stronger checked-wrapper contract. No silent CPU answer substitution is added; historical controls' explicit tie repair is retained and counted.

**Units, sessions and timing.** Exactly **12 separately initiated performance processes**, sequential on one laptop, with 10 seconds idle between processes and no concurrent experiment. Two warm-up calls per method/case; six timed blocks per case. Method base order is seeded, followed by six cyclic rotations so each method occupies each position once; reverse order by session parity. Randomize configuration/query order using frozen seeds. Native preparation occurs before timing. Each method retains its original buffer management. Time starts before required validation/preparation and ends after staging, synchronous execution, retrieval, ordering and required verification/tie repair. Independent exact reference creation and comparison are outside timing. Record compilation/preparation and warm-up separately, placement, versions, power plan, AC connection and battery saver state. Keep AC connected, saver off, and the audited Balanced plan; version/plan changes invalidate environmental eligibility and are reported, not hidden. Background/thermal variation is not assumed eliminated.

**Sample-size justification.** Current old-query pilot ratios are about 1.250,1.205,1.257; historical log SD is 0.0311. Planning SD is the maximum of 0.07 and twice each pilot SD. With 12 sessions, Student-t planning halfwidth is 0.04448 log units (about 4.5% ratio uncertainty). Eight queries reduce dependence on a single input, while the session remains the inferential unit. This is a precision-based design, not guaranteed power to distinguish a ratio narrowly above 1.10. Session count is fixed, without significance-driven extension or early stopping. Actual achieved uncertainty will be reported.

**Primary estimand/test.** SIFT1M N=1M,K=10,W=256 on the eight frozen queries. Within each session/query take each method's six-call median. Form `log(INT32 median / FP32 median)`; average eight query effects within each session. Estimate the exponential mean of 12 session effects. Use a two-sided exact sign-flip test against zero (4,096 permutations, alpha=0.05), conditional on sign symmetry/exchangeability of paired session effects under the null. Report its assumption explicitly; process separation alone does not prove independence. Obtain a 95% percentile bootstrap interval by resampling whole session effects 50,000 times. Declare a statistically/practically meaningful FP32 advantage only if p<0.05, the interval's lower bound exceeds **1.10**, and every primary checked-method warm-up/timed output is accepted and exact. A mixed, null or negative result is valid research evidence.

**Secondary family.** At the full-corpus K=10,W=256 panel, compare FP32 with native NPU, FP16 static, C++ and CUDA separately in each dataset (12 tests), plus FP32 versus INT32 in SciFact and FiQA (two tests). Use the same session statistic, two-sided sign-flip tests and **Holm correction across all 14**. Primary is separate. Unavailable comparisons receive no favorable inference; mark not estimable and retain p=1 for multiplicity accounting. Nominal intervals are not simultaneous familywise intervals. Unsafe-control comparisons always retain numerical qualifications.

**Sensitivity and distributions.** Report 20,000-resample crossed session/query bootstrap intervals for query generalization, pair adjacent sessions into six temporal blocks for bootstrap/sign-flip sensitivity, lag-one session correlation, and leave-one-query-out effect ranges. These do not replace the primary estimand. N/K/W sensitivity estimates are descriptive, without extra significance claims. Report raw-distribution summaries, session/query medians, P95 with its sampling limitations, reciprocal-median sequential query throughput and session uncertainty; never infer concurrent throughput. Do not measure energy or peak memory.

**Numerical panel.** Exactly 54 fresh constructions: W in {128,256,512}, K in {1,10,100}, and six families (positive subnormal, negative subnormal, normal neighbors, mixed ties/extremes, signed-zero-only, cross-tile subnormal boundary). Exact N, seeds and constructions are frozen in code/JSON. Irregular lengths span W+1,2W-1,2W+1 and exercise internal padding. Three separately initiated numerical processes repeat the same panel twice per executable. Compare raw default FP16, unprotected promotion, TopK-only, Reshape-only, combined preservation and stable INT32; use independent scalar/lexicographic reference plus explicit CPU graph controls. Save raw IDs/values and placement. INT32 value consistency is in the declared key representation, with source ranking decoded through the known encoding. These are fixed-panel counts, not binomial population failure-rate estimates or independent defect counts. An additional fresh rerun of the existing adjacent-pair suite may be reported as independent bounded-exhaustive replication, separately from this panel; it supplies no universal claim.

**Failure and stopping rules.** Save every construction/compile/runtime error, rejection and accepted mismatch. Do not erase or replace unfavorable calls, drop query ties, or time only successful iterations. Invalid checked primary rows prevent a success/advantage claim and complete-case inference; report that missing evidence. Construction failures in a secondary configuration do not prevent testing other supported methods. Warm-up errors are retained. Failed/rejected attempt latencies are time-to-rejection, not valid-result speedups. No latency-outlier exclusion, performance-based rerun or sample extension is allowed. Abort only for source/input digest violation, environmental mismatch, device unavailability or infrastructure failure, preserve partial output and report the gap. Exactly 12 scheduled attempts; no automatic replacements. No source change after freezing; a necessary repair requires a separately documented amendment and must not reinterpret already collected results as pre-repair confirmation.

**Readiness.** The final decision concerns empirical evidence for C1–C3, not a new algorithm, universal opaque-device proof, unique silicon cause, or publication acceptance. A positive speedup or small p value is neither required nor sufficient. The final analysis must recheck saved raw outputs, regenerate six machine-readable tables and state single-device/version, temporal and query-sampling limitations. No manuscript is written in this phase.
